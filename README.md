# Brobot

Brobot is a desktop-style chat application inspired by the chaotic internet
aesthetic of the 2000s.

The goal is to eventually create a real-time chat application featuring an
AI character named Brobot.

## Current Version

### v0.1 — Static Chat Interface

Currently built with:

- HTML
- CSS

Current features:

- Brobot chat window
- Friend list
- Chat messages
- Message input
- Early-2000s internet-inspired styling
